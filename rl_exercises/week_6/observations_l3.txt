Observations:
The SAC implementation uses the main components from the paper: a stochastic tanh-Gaussian actor, twin Q-networks, target Q-networks, replay buffer updates, and entropy regularization. The Pendulum-v1 result improves to a reasonable negative return within 12000 steps, especially for seeds 0 and 1.

The SAC paper claims that can be checked here are mostly qualitative. SAC is off-policy and reuses old transitions from replay, while PPO is on-policy and updates from fresh rollouts. SAC also supports continuous action spaces directly, which is why Pendulum-v1 is a natural test environment. The PPO implementation in this repository uses a categorical discrete policy, so a direct same-environment comparison against PPO would require adding a continuous-action PPO policy first.
